> ### АНТИВИРУСЫ
> Антивирус может отреагировать на WinDivert.  
> Этот инструмент перехватывает и фильтрует трафик, поэтому он необходим для работы zapret.
> WinDivert способен использоваться как легитимными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и перемещается в карантин. Обычно обнаружение называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете настройку исключений, предпочтительно добавить исключение. При отсутствии уверенности отключите обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS).
   * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется.
   * На роутерах Keenetic активируйте параметр "Транзит запросов". При выключенной опции Secure DNS на компьютере может работать некорректно.

2. Откройте [страницу последнего релиза](https://github.com/FairFlyChant/zapret-discord-youtube/releases/latest) и скачайте архив в формате zip или rar.

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите подходящий файл.
   * Чтобы подобрать стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
   * Для установки стратегии в автозапуск используйте **`service.bat`** -> `Install Service` и укажите подходящий вариант.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) запускают стратегии вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому перебирайте стратегии, включая **ALT**, **FAKE** и другие, пока не найдёте подходящую именно для вашей системы.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** устанавливает выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** переключает режим обхода для игр и других программ, использующих UDP и TCP-порты выше 1023.  
  После изменения параметра стратегию нужно перезапустить.  
  Текущее состояние включения или выключения отображается в скобках.
  - **`IPSet Filter`** управляет фильтрацией сервисов из `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret работает, а с ним перестаёт.  
  В скобках указывается состояние:
    - `none` - ни один IP не проверяется;
    - `loaded` - IP проверяется на наличие в списке;
    - `any` - под фильтр попадает любой IP.
  - **`Auto-Update Check`** включает или выключает автоматический поиск обновлений.
  - **`Replace active fakes`** заменяет используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** загружает актуальную версию `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts для <ins>исправления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы клиента.
  - **`Run Tests`** проверяет стратегии:
    - `Standard tests` тестирует сайты из `utils/targets.txt`;
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач. Если этого не произошло, обратитесь к [#522](https://github.com/FairFlyChant/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит

1. Откройте командную строку от имени администратора.
2. Выполните команды по очереди:

   `netsh winsock reset`

   `netsh int ip reset all`

   `netsh winhttp reset proxy`

   `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не работает телеграм (веб версия)

Откройте **`service.bat`** и запустите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:

- скопируйте весь текст из открытого блокнота;
- от имени администратора откройте текстовым редактором файл `hosts` в появившемся каталоге;
- вставьте скопированный текст в конец файла или замените ранее добавленные аналогичные строки;
- сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантирована. При отсутствии результата используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/FairFlyChant/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Даже если определённый вариант некоторое время работает, обнаружение его параметров может привести к прекращению работы.
> В репозитории есть разные стратегии обхода. Если ни одна не подходит, создайте новую на базе существующей, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

Проверьте следующее:

- нет ли ошибок в `service.bat` -> `Run Diagnostics`;
- присутствует ли адрес нужного ресурса в списке доменов или IP;
- работают ли другие стратегии, в том числе **`ALT`** и **`FAKE`**;
- помогает ли полная переустановка по инструкции ниже.

Дополнительная информация находится в [#765](https://github.com/FairFlyChant/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните добавленные вами ресурсы и другие данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите старый каталог zapret.
- Скачайте свежую версию `zapret-discord-youtube-...` со [страницы релизов](https://github.com/FairFlyChant/zapret-discord-youtube/releases).
- Откройте свойства архива через контекстное меню. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новый каталог в корне диска. В пути не должно быть пробелов и специальных символов.
- По очереди запускайте разные скрипты `general`. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- Найдя рабочую стратегию, установите её в автозапуск через `service.bat` -> `Install Service`.

### Не работает игра или приложение при включённом запрете

Убедитесь, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе обход может повлиять на ресурсы, которые вы не собирались фильтровать.

### Античит ругается на WinDivert

Инструкция по решению проблемы приведена [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Откройте командную строку Windows через Win+R и `cmd`, затем узнайте имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу, подставив полученное имя вместо `название_из_первого_шага`:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- Дополнительные сведения: [#251](https://github.com/FairFlyChant/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение после очистки.
- Откройте Discord в браузере по адресу https://discord.com/app. Если браузерная версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/FairFlyChant/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Используйте [tg-ws-proxy](https://github.com/FairFlyChant/tg-ws-proxy).
- Либо выберите бесплатный MTProto-прокси из интернета.

### Не работают игры

Игр много, и проверить или исправить каждую из них невозможно.

Для начала попробуйте универсальную последовательность:

- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить доступ к большому числу сайтов. Не оставляйте его включённым постоянно. Лучше определить все IP-адреса, используемые игрой, и добавить их в `ipset-all.txt`.

Если проблема останется, создайте обсуждение в разделе [Discussions](https://github.com/FairFlyChant/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

Опишите проблему [в этом разделе](https://github.com/FairFlyChant/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Добавляйте адреса нужных ресурсов в соответствующие файлы:

- **`list-general-user.txt`** - домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP-сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется;
- **`ipset-all.txt`** - IP-адреса и подсети;
- **`ipset-exclude-user.txt`** - IP-адреса и подсети для исключения.

Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
